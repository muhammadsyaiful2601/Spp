# Panduan Hosting dan Deploy

Aplikasi terdiri dari frontend React/Vite dan backend API Laravel.

- **Shared hosting cPanel:** ikuti [Panduan Instalasi di cPanel](CPANEL.md)
  untuk memilih paket hosting, mengatur domain dan document root, menginstal
  backend dari Terminal, memasang frontend, mengaktifkan HTTPS, mengatur SMTP,
  membuat akun pertama, serta melakukan backup dan update.
- **VPS Ubuntu:** gunakan instalasi PHP 8.3+, Composer 2, MySQL, Node.js 22,
  web server, dan HTTPS. Perintah cPanel tidak berlaku untuk VPS, demikian
  juga perintah VPS tidak berlaku untuk shared hosting.

Nama domain pada panduan adalah contoh. Ganti dengan domain milik sekolah.
